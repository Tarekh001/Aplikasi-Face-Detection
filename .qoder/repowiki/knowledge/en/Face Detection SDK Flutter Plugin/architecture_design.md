- **Dart API layer** (`lib/facesdk_plugin.dart`) delegates all calls to `FacesdkPluginPlatform.instance`, following the federated plugin pattern defined in `facesdk_plugin_platform_interface.dart`.
- **Method channel implementation** (`facesdk_plugin_method_channel.dart`) maps Dart API methods to native invocations on the `facesdk_plugin` channel (e.g., `setActivation`, `init`, `extractFaces`, `similarityCalculation`).
- **Platform view interface** (`facedetection_interface.dart`) defines `FaceDetectionViewController` for per-view method channels (`facedetectionview_<id>`), enabling real-time face detection callbacks from native camera streams.
- **Android native layer** (`android/src/main/kotlin/.../FacesdkPlugin.kt`) implements `FlutterPlugin`, `MethodCallHandler`, and `ActivityAware`; registers `FaceDetectionViewFactory` as a platform view factory; delegates to `FaceSDK` static APIs from bundled `libfacesdk` AAR dependency (declared in `build.gradle`).
- **iOS native layer** (`ios/Classes/FacesdkPlugin.swift`) implements `FlutterPlugin` registration with method channel handler; `FaceDetectionViewFactory` creates `FaceDetectionFlutterView` instances that use `AVCaptureSession` for camera capture; delegates to `FaceSDK` from vendored `facesdk.framework` (declared in `facesdk_plugin.podspec`).
- **Shared data contract**: both platforms return identical face extraction structures (bounding box coordinates, liveness score, pose angles, templates byte array, cropped face image) from `extractFaces` and real-time `onFaceDetected` callbacks.
